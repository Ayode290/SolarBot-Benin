# SolarBot Bénin ☀️

**Assistant IA avec Qwen qui génère un devis de panneaux solaires en 30s pour les particuliers au Bénin.**

Projet soumis au Hackathon Qwen Agent Challenge.

## 🎯 Problème résolu
Au Bénin, faire un devis solaire prend 1h minimum. Il faut calculer les watts, choisir les batteries, l'onduleur, le nombre de panneaux. La plupart des clients n'y comprennent rien et renoncent.

SolarBot Bénin résout ça : le client répond à 4 questions simples et l'IA Qwen génère un devis complet : kit recommandé, prix estimé, ROI sur 5 ans.

## ✨ Fonctionnalités
- **Devis en 30 secondes** : Entre ta consommation, ton budget, ta région
- **Recommandation IA** : Qwen choisit le meilleur kit solaire selon tes besoins
- **Calcul ROI** : Estimation des économies sur 5 ans
- **Export PDF** : Télécharge ton devis pour l'envoyer au client
- **Interface en Français** : Simple, pensée pour le marché local

## 🛠️ Construit avec
- **Backend** : Python, Flask
- **Frontend** : HTML, CSS, JavaScript
- **IA** : API Qwen / QwenCloud
- **Base de données** : SQLite pour les tarifs locaux
- **Déploiement** : GitHub, Streamlit Cloud
